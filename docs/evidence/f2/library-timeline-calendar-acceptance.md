# F2 #12 — Library, Timeline and Calendar acceptance

Execution: complete for the current source baseline and the available Android runtime.

## Implemented

Library now has a native route alongside Timeline and Calendar. It uses the source summary endpoint and supports title/content search, symbol, review status, inclusive civil-date bounds, all four server sort orders, page sizes 10/20/50/100, previous/next navigation and canonical total/page counts. If a deletion makes the current page invalid, the controller moves to the server's last valid page. Timeline retains its 20-row load-more behavior, groups loaded entries by civil month, and shows the server total separately from the number loaded. A confirmed write refreshes the visible Library page or all loaded Timeline pages without resetting the query or Calendar's selected date.

Library is registered inside the authenticated tab shell, preserving the app header, safe area, bottom navigation and normal back behavior. Calendar continues to derive Today from the account timezone, query exact month civil-date bounds, distinguish unavailable activity from a confirmed empty date, and offer Quick Diary or the complete editor on empty days. When an encrypted Quick draft already exists, Calendar asks before resuming it and leaves its original date/content intact.
