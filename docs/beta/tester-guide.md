# Trade Basic Beta 測試指南

這是受邀 Android 測試版，目前準備中的版本尚未開放邀請。請等主辦方提供經驗收的安裝檔、個別帳號、正式支援管道與資料政策後再開始。

## 安裝與登入

只使用主辦方私下提供的 Trade Basic Beta 安裝檔。安裝連結不等於帳號授權；每人使用自己經核准的帳號，不共用登入資料。Beta 與開發版是不同安裝，不會自動帶入開發版草稿。

此版本沒有自行註冊或自動密碼重設。需要帳號、無法登入或忘記密碼時，開啟登入頁的「取得帳號／登入協助 · Beta／Help」，透過其中的正式支援管道請主辦方人工協助。若畫面表示支援尚未設定，先向提供安裝檔的主辦方確認，不要開始外部測試。

在 Android 開啟主辦方提供的 APK；若系統要求，僅對這次使用的下載／檔案工具允許「安裝未知應用程式」，安裝後關閉該權限。先比對主辦方公布的版本／Build，再開啟 Trade Basic Beta。登入只需要個別帳號，不需要輸入 API 網址、token 或開發伺服器設定。

更新時，直接安裝主辦方提供的較新版本。若安裝失敗，請保留原安裝並聯絡支援；不要解除安裝、清除應用程式資料或改裝舊版。這些操作可能造成草稿遺失。

## 開始記錄

1. 用 **Quick Diary** 記下想法，再明確按下儲存。草稿會先加密保存在這台裝置。
2. 用 **Timeline／搜尋／Calendar** 找到日誌。Calendar 可從空白日期開始新的草稿；已有草稿時先選擇繼續原稿。
3. 開啟日誌的 **Review**，選擇結果、填寫反思，再按 **Complete review**；編輯已完成的複盤時按 **Save review changes**。更新會改變伺服器上的 reviewedAt 時間。

首次說明可以關閉，之後在登入頁或 **Account → Beta／Help** 再次查看。

## 約十分鐘的小任務

1. 安裝並使用自己的帳號登入。
2. 寫一篇不含敏感資訊的測試日誌，明確儲存後開啟 Detail。
3. 用搜尋或 Calendar 找回它，再返回原畫面。
4. 寫一則 Review，選擇結果並明確完成，確認 Detail／Queue 更新。
5. 另外留下一份未完成草稿，等畫面顯示本機已保存後關閉再開啟，確認文字仍在。這一步不要按確認捨棄或登出。
6. 回報任何失敗或令人困惑的步驟；若結果未確認，保留原狀並聯絡支援。

回報請包含 **App 版本／Build、手機型號、Android 版本、重現步驟、預期與實際結果**。可選擇附上自己檢查過且遮蔽私人內容的截圖，或已檢視的診斷摘要；不必提供日誌正文。

## 看懂儲存狀態

* **草稿已存於裝置**：只有本機保存，不代表伺服器已收到。Review 輸入時的自動儲存也是本機草稿。
* **伺服器儲存已確認**：伺服器已回覆成功。
* **結果未確認／unknown**：請保留草稿，使用畫面的唯讀檢查，或聯絡支援。不要重複提交；看見相同或舊內容都不一定能證明原請求已結束。
* **已儲存但重新讀取失敗**：只需重試讀取，不要再次提交。

離線時請保留裝置與草稿，恢復連線後再檢查。明確捨棄或確認登出會移除目前帳號的本機草稿，但不能取消或撤銷可能已送到伺服器的寫入。登入期限到期則保留草稿。

## 資料與協助

確認送出的日誌與複盤保存在此 Beta 服務的伺服器。本機 Quick Diary／Review 草稿使用 SQLCipher 加密，這不代表端對端加密。解除安裝會失去裝置草稿與金鑰；請勿以此排除故障。

實際伺服器存放位置、保留或移除安排，以及資料刪除申請方式，請以主辦方確認並顯示於 **Beta／Help → 資料與草稿** 的說明為準。在這些資訊未確認前，不開始外部測試。本指南不承諾尚未確認的保留期限或刪除結果。

遇到問題時：

1. 從 Account、登入頁或相關錯誤畫面開啟 **Beta／Help · Report a problem**。
2. 點選 **檢視診斷摘要**，先檢查，再長按選取複製；也可明確選擇分享，透過畫面列出的正式支援管道聯絡。
3. 說明當時操作步驟、預期結果與看到的儲存狀態。摘要只包含版本／Build、系統、環境、畫面代碼及可用的錯誤／請求代碼，不含日誌或帳號。補充描述或截圖時，也請避開私人內容。

不要提供密碼、token、加密金鑰、日誌／複盤正文、草稿資料庫或其他人的資料。程式不會自動上傳診斷或私人內容。畫面錯誤的「重新顯示畫面」不會捨棄草稿或自動重送寫入。

## 本次測試範圍

可測試登入與恢復、Quick Diary、加密草稿、Timeline／搜尋／篩選、Calendar，以及 Review 完成與更新。複盤重新排程／回到待辦、完整日誌編輯／刪除／範本、Portfolio、Watchlist、通知、SSO、iOS 與商店發佈不在本次範圍。

測試版遇到無法確定的儲存結果時，以保留資料並尋求協助為優先，不要靠反覆儲存或重新安裝嘗試修復。

Review 儲存前的版本檢查無法保證阻止其他裝置同時覆寫；目前沒有伺服器原子條件更新。Completed 清單只提供伺服器最近 50 筆。
